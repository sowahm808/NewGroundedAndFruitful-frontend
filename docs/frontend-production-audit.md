# Frontend production audit

Audit date: 2026-08-19

## Evidence and root cause

The route table used one `UnavailablePageComponent` loader for all child, mentor, observer, administrator, account-state, 404, and authorization destinations. In particular, `/admin/quarters` was generated by the same administrator route map, so it could never call a quarters API. The old shell was a fixed 230px sidebar plus a five-link mobile bottom bar; it had no toolbar, menu drawer, profile access, or logout control.

The repository contains no backend source, OpenAPI document, generated client, response fixture, authenticated Playwright identity, or emulator seed. Attempts to inspect the deployed host's `/openapi.json`, `/api/openapi.json`, `/api/v1/openapi.json`, `/docs`, `/api-docs`, `/swagger.json`, and authenticated quarters resource were blocked by the execution environment's HTTP CONNECT proxy (HTTP 403 before reaching the host). Consequently no request or response fields have been inferred.

## Verified contracts

The checked-in application has one verified session integration: `GET /auth/session`, beneath the environment API base, returns the documented `data` envelope used by `AuthService`. Existing dedicated parent features use these repository-documented paths:

- `GET /parent/dashboard`
- `GET /parent/children` and `GET /parent/children/{childId}`
- `GET` and `PATCH /parent/character`
- `GET` and `POST /parent/observations`
- `GET /parent/family/activities` and `POST /parent/family/activities/{id}/completions`
- `GET /parent/academic-support/configuration`
- `GET` and `POST /parent/academic-support/requests`
- `GET /parent/reports`

All use the central API client and Firebase bearer-token interceptor. No component contains the production API hostname.

## Quarters contract finding

None of the following required administration contracts is documented or verifiable in the repository, including authorization scopes, envelopes, fields, pagination, version headers, validation errors, or transition commands:

- `GET /admin/quarters`
- `GET /admin/quarters/{quarterId}`
- `POST /admin/quarters`
- `PATCH /admin/quarters/{quarterId}`
- `POST /admin/quarters/{quarterId}/transitions`

`/admin/quarters` now has a dedicated lazy standalone page. It reports this exact dependency and does not issue a speculative request, fabricate an empty response, or expose nonfunctional mutation controls. To finish it, backend OpenAPI must define the quarter identifier/name, authoritative status and current marker, start/end dates, timezone, server-derived week, team target, cursor/filter schema, capability/authorization representation, create/update commands, lifecycle transition command, optimistic concurrency/version mechanism, error envelope, and request-ID location.

Editing requires a published authorized profile-update endpoint.

## Application-shell remediation

One authenticated shell now derives stable navigation links from typed role-aware configuration and the authoritative backend session. It provides a sticky semantic toolbar, responsive persistent desktop drawer, sub-960px hamburger and sliding focus-trapped drawer, backdrop, Escape close, route-close, focus restoration, body-scroll locking, visible focus, 44px controls, reduced-motion handling, and width-safe routed content. The toolbar renders session-derived initials/display name and an accessible keyboard-operated Profile/Logout menu. Logout is duplicate-safe, closes overlays, calls Firebase through `AuthService`, clears only in-memory application state, and replaces navigation history with `/auth/login`; a safe error is shown if sign-out rejects.

## Verification limitations and release dependencies

Baseline Angular commands cannot compile in this container because it provides Node 20.20.2 while Angular 22 requires Node 22.22.3, 24.15.0, or 26.0.0 and this project declares Node 26. Playwright cannot start the Angular dev server for the same reason. Authenticated E2E scenarios additionally require approved emulator seed identities and real contract fixtures; tests must not target production or fabricate private records.

No mock production data, user identity, role, quarter, team, total, status, point value, or activity record was introduced.
